## はじめに

SwiftUIの`fullscreenCover`モディファイアは、全画面モーダルを表示する際に便利ですが、デフォルトではスワイプダウンで閉じることができません。この記事では、スクロールジェスチャーで自然に閉じられるようにするエクステンションの実装方法を紹介します。

## 実装したい機能

- fullscreenCoverで表示したビューを、上から下へのスクロールジェスチャーで閉じる
- スクロール量に応じてビューをドラッグできる
- 一定の閾値を超えたら自動的にクローズする
- スムーズなアニメーションで自然な操作感を実現

## 実装

### DragGestureを使った基本実装

まずは、`DragGesture`を使ってスクロール量を追跡し、閾値を超えたら閉じる仕組みを作ります。

```swift
import SwiftUI

extension View {
    func dismissableFullscreenCover(
        isPresented: Binding<Bool>,
        threshold: CGFloat = 100
    ) -> some View {
        self.modifier(
            DismissableFullscreenCoverModifier(
                isPresented: isPresented,
                threshold: threshold
            )
        )
    }
}

struct DismissableFullscreenCoverModifier: ViewModifier {
    @Binding var isPresented: Bool
    let threshold: CGFloat
    @State private var dragOffset: CGFloat = 0

    func body(content: Content) -> some View {
        content
            .offset(y: max(0, dragOffset))
            .gesture(
                DragGesture()
                    .onChanged { value in
                        if value.translation.height > 0 {
                            dragOffset = value.translation.height
                        }
                    }
                    .onEnded { value in
                        if dragOffset > threshold {
                            withAnimation(.easeOut(duration: 0.3)) {
                                dragOffset = UIScreen.main.bounds.height
                            }
                            DispatchQueue.main.asyncAfter(deadline: .now() + 0.3) {
                                isPresented = false
                                dragOffset = 0
                            }
                        } else {
                            withAnimation(.spring()) {
                                dragOffset = 0
                            }
                        }
                    }
            )
    }
}
```

### 使用例

```swift
struct ContentView: View {
    @State private var showFullscreen = false

    var body: some View {
        VStack {
            Button("Show Fullscreen") {
                showFullscreen = true
            }
        }
        .fullscreenCover(isPresented: $showFullscreen) {
            ModalView()
                .dismissableFullscreenCover(
                    isPresented: $showFullscreen,
                    threshold: 150
                )
        }
    }
}

struct ModalView: View {
    var body: some View {
        ZStack(alignment: .top) {
            Color.white
                .ignoresSafeArea()

            VStack(spacing: 20) {
                // ドラッグインジケーター
                Capsule()
                    .fill(Color.gray.opacity(0.3))
                    .frame(width: 40, height: 5)
                    .padding(.top, 8)

                Text("Fullscreen Content")
                    .font(.largeTitle)

                Spacer()
            }
        }
    }
}
```

## ポイント解説

### 1. オフセットの制御

```swift
.offset(y: max(0, dragOffset))
```

`max(0, dragOffset)`を使うことで、上方向へのドラッグ（負の値）を無効化し、下方向のみドラッグ可能にしています。

### 2. 閾値判定

```swift
if dragOffset > threshold {
    // 閉じる処理
} else {
    // 元の位置に戻す
}
```

ユーザーが指を離した時点でのドラッグ量が閾値を超えていれば閉じる、超えていなければ元の位置に戻すという挙動を実装しています。

### 3. アニメーション

```swift
withAnimation(.easeOut(duration: 0.3)) {
    dragOffset = UIScreen.main.bounds.height
}
```

閉じる際は画面全体の高さ分オフセットを与えることで、スムーズに下へスライドアウトします。

### 4. 状態のリセット

```swift
DispatchQueue.main.asyncAfter(deadline: .now() + 0.3) {
    isPresented = false
    dragOffset = 0
}
```

アニメーション完了後に`isPresented`を`false`にし、`dragOffset`をリセットすることで、次回の表示に備えます。

## 改善案

### スクロールビューとの共存

上記の実装では、コンテンツ内にScrollViewがある場合、ジェスチャーが競合する可能性があります。以下のように改善できます：

```swift
struct DismissableFullscreenCoverModifier: ViewModifier {
    @Binding var isPresented: Bool
    let threshold: CGFloat
    @State private var dragOffset: CGFloat = 0
    @GestureState private var isDragging = false

    func body(content: Content) -> some View {
        content
            .offset(y: max(0, dragOffset))
            .simultaneousGesture(
                DragGesture(minimumDistance: 0)
                    .updating($isDragging) { _, state, _ in
                        state = true
                    }
                    .onChanged { value in
                        // スクロール位置が一番上の時のみドラッグを許可
                        if value.translation.height > 0 && value.startLocation.y < 100 {
                            dragOffset = value.translation.height
                        }
                    }
                    .onEnded { value in
                        if dragOffset > threshold {
                            withAnimation(.easeOut(duration: 0.3)) {
                                dragOffset = UIScreen.main.bounds.height
                            }
                            DispatchQueue.main.asyncAfter(deadline: .now() + 0.3) {
                                isPresented = false
                                dragOffset = 0
                            }
                        } else {
                            withAnimation(.spring()) {
                                dragOffset = 0
                            }
                        }
                    }
            )
    }
}
```

### ドラッグ速度を考慮

```swift
.onEnded { value in
    let velocity = value.predictedEndLocation.y - value.location.y
    if dragOffset > threshold || velocity > 500 {
        // 閉じる処理
    } else {
        // 元に戻す処理
    }
}
```

速度を考慮することで、軽いフリックでも閉じられるようになります。

## まとめ

SwiftUIの`fullscreenCover`にスクロールで閉じる機能を追加するエクステンションを実装しました。この実装により、ユーザーにとってより直感的な操作感を提供できます。

実装のポイント：
- `DragGesture`でスワイプ量を追跡
- 閾値を超えたら自動でクローズ
- アニメーションで自然な動きを実現
- `simultaneousGesture`でScrollViewとの共存も可能

この実装をベースに、プロジェクトのニーズに合わせてカスタマイズしてみてください。

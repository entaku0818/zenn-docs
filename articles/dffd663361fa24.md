実際にAndroidアプリケーションでExoPlayerを使用してライブストリームを再生する完全なサンプルを作成するためには、以下の手順を含める必要があります。このサンプルは、基本的なライブストリーム再生機能を実装するもので、実際に動作させるためには、適切なライブストリームURLを設定する必要があります。

### 1. Gradleファイルに依存関係を追加

`build.gradle`（appレベル）に以下の依存関係を追加します。

```gradle
dependencies {
    implementation 'com.google.android.exoplayer:exoplayer-core:2.15.1'
    implementation 'com.google.android.exoplayer:exoplayer-hls:2.15.1'
    implementation 'com.google.android.exoplayer:exoplayer-ui:2.15.1'
}
```

### 2. `AndroidManifest.xml`にパーミッションを追加

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="your.package.name">

    <uses-permission android:name="android.permission.INTERNET"/>
    
    <application
        ...
        >
        ...
    </application>
</manifest>
```

### 3. レイアウトにPlayerViewを追加

`activity_main.xml`などのレイアウトファイルに`PlayerView`を追加します。

```xml
<com.google.android.exoplayer2.ui.PlayerView
    android:id="@+id/player_view"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"/>
```

### 4. ExoPlayerでライブストリームを再生するためのコード

`MainActivity.kt`などのアクティビティに以下のコードを追加します。

```kotlin
import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity
import com.google.android.exoplayer2.ExoPlayer
import com.google.android.exoplayer2.MediaItem
import com.google.android.exoplayer2.ui.PlayerView
import com.google.android.exoplayer2.source.hls.HlsMediaSource
import com.google.android.exoplayer2.upstream.DefaultHttpDataSource

class MainActivity : AppCompatActivity() {
    private lateinit var playerView: PlayerView
    private lateinit var player: ExoPlayer

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        playerView = findViewById(R.id.player_view)
        initializePlayer()
    }

    private fun initializePlayer() {
        player = ExoPlayer.Builder(this).build()
        playerView.player = player

        // Replace "YOUR_LIVE_STREAM_URL" with your actual live stream URL.
        val mediaItem = MediaItem.fromUri("YOUR_LIVE_STREAM_URL")
        val mediaSource = HlsMediaSource.Factory(DefaultHttpDataSource.Factory())
            .createMediaSource(mediaItem)

        player.setMediaSource(mediaSource)
        player.prepare()
        player.playWhenReady = true
    }

    override fun onStop() {
        super.onStop()
        player.release()
    }
}
```

このサンプルコードは、アプリケーションが起動するとライブストリームの再生を開始し、アプリが停止するとプレイヤーを解放する基本的な流れを実装しています。`YOUR_LIVE_STREAM_URL`は、実際のライブストリームURLに置き換えてください。

これで、ExoPlayerを使用してAndroidデバイス上でライブストリームを再生するアプリケーションの基本的なセットアップが完了しました。これを基に、さらにカスタマイズや機能追加を行っていくことが可能です。

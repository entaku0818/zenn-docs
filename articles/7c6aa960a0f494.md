# Zenn CLIを使ってみた

この記事では、Zenn CLIのセットアップと使い方について簡単に紹介します。

## セットアップ手順

1. npmパッケージとしてZenn CLIをインストール
```bash
npm init --yes
npm install zenn-cli
```

2. Zenn用のディレクトリ構造を初期化
```bash
npx zenn init
```

3. 新しい記事を作成
```bash
npx zenn new:article
```

4. 記事をプレビュー
```bash
npx zenn preview
```

## 記事の編集

記事は`articles`ディレクトリに`.md`ファイルとして保存されます。
Front Matterでタイトルやトピックなどのメタデータを設定します。

## GitHubとの連携

記事を公開するには、ZennとGitHubリポジトリを連携させる必要があります。
連携後、リポジトリにプッシュすると自動的に記事が公開されます。

# CIパイプラインで環境変数を安全に扱う方法

モバイルアプリ開発において、APIキーや各種クレデンシャルの管理は重要な課題です。本記事では、CIパイプライン上で環境変数を安全に扱い、ビルド時に自動的にInfo.plistに反映させる方法を解説します。

## はじめに

モバイルアプリ開発では、以下のような秘匿情報を扱うことが多いです：

- アナリティクスツールのAPIキー
- 広告SDKの識別子
- 課金システムのキー
- クラッシュレポートツールのトークン

これらの情報をソースコードにハードコードすることは、セキュリティ上のリスクがあります。代わりに、環境変数として管理し、ビルド時に自動的に設定する方法が推奨されます。

## 実装例

以下は、シェルスクリプトを使って環境変数をiOSアプリのInfo.plistに反映させる例です。

```bash
#!/bin/sh
echo "Starting pre-build script..."

# プロジェクトのルートディレクトリに移動
cd $CI_PRIMARY_REPOSITORY_PATH/VoiLog/

# 必要な環境変数の定義
REQUIRED_VARS=(
    "ROLLBAR_KEY"
    "ADMOB_KEY"
    "RECORD_ADMOB_KEY"
    "REVENUECAT_KEY"
    "PLAYLIST_ADMOB_KEY"
)

# 未設定の環境変数をチェック
MISSING_VARS=()
for VAR in "${REQUIRED_VARS[@]}"; do
    if [ -z "${!VAR}" ]; then
        MISSING_VARS+=($VAR)
    fi
done

# エラーハンドリング
if [ ${#MISSING_VARS[@]} -ne 0 ]; then
    echo "Error: 以下の環境変数が設定されていません:"
    printf '%s\n' "${MISSING_VARS[@]}"
    exit 1
fi

# Info.plistへの書き込み
plutil -replace ROLLBAR_KEY -string "$ROLLBAR_KEY" Info.plist
plutil -replace ADMOB_KEY -string "$ADMOB_KEY" Info.plist
plutil -replace RECORD_ADMOB_KEY -string "$RECORD_ADMOB_KEY" Info.plist
plutil -replace REVENUECAT_KEY -string "$REVENUECAT_KEY" Info.plist
plutil -replace PLAYLIST_ADMOB_KEY -string "$PLAYLIST_ADMOB_KEY" Info.plist

# 結果の確認
echo "Info.plistの更新を確認中..."
plutil -p Info.plist

echo "環境変数の設定が完了しました"
exit 
```

## スクリプトの解説

### 1. 必要な環境変数の定義

```bash
REQUIRED_VARS=(
    "ROLLBAR_KEY"
    "ADMOB_KEY"
    "RECORD_ADMOB_KEY"
    "REVENUECAT_KEY"
    "PLAYLIST_ADMOB_KEY"
)
```

配列を使用して、必要な環境変数を定義します。この方法により、新しい環境変数の追加や削除が容易になります。

### 2. 環境変数のバリデーション

```bash
MISSING_VARS=()
for VAR in "${REQUIRED_VARS[@]}"; do
    if [ -z "${!VAR}" ]; then
        MISSING_VARS+=($VAR)
    fi
done
```

各環境変数が設定されているかチェックし、未設定の変数があればMISSING_VARS配列に追加します。間接参照（`${!VAR}`）を使用することで、変数名を動的に評価できます。

### 3. エラーハンドリング

```bash
if [ ${#MISSING_VARS[@]} -ne 0 ]; then
    echo "Error: 以下の環境変数が設定されていません:"
    printf '%s\n' "${MISSING_VARS[@]}"
    exit 1
fi
```

未設定の環境変数が存在する場合、エラーメッセージを表示してスクリプトを終了します。これにより、必要な環境変数が設定されていない状態でのビルドを防ぐことができます。

### 4. Info.plistへの書き込み

```bash
plutil -replace ROLLBAR_KEY -string "$ROLLBAR_KEY" Info.plist
```

`plutil`コマンドを使用して、環境変数の値をInfo.plistに書き込みます。`-replace`オプションにより、既存の値を上書きします。

## セキュリティ上の注意点

1. **環境変数の管理**
   - CIツールの環境変数設定機能を使用し、値を暗号化して保存する
   - アクセス権限を適切に設定し、閲覧できる人を制限する

2. **ログの取り扱い**
   - デバッグ時のログ出力で環境変数の値が露出しないよう注意する
   - CIのログ設定で、秘匿情報がログに残らないようにする

3. **バージョン管理**
   - `.gitignore`に秘匿情報を含むファイルを追加する
   - 環境変数のサンプルファイル（例：`.env.example`）をリポジトリに含める

## まとめ

CIパイプラインで環境変数を適切に扱うことは、アプリのセキュリティを確保する上で重要です。本記事で紹介したスクリプトを基に、プロジェクトの要件に合わせてカスタマイズすることで、より安全な開発環境を構築できます。
